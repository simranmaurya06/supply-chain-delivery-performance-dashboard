# Supply Chain Delivery Performance Dashboard

## Overview

This project presents an interactive Power BI dashboard built using the DataCo Supply Chain Dataset. The dashboard analyzes delivery performance across markets, shipping modes, product categories, and products to identify factors contributing to delayed deliveries and operational inefficiencies.

The objective is to transform raw supply chain data into actionable business insights that can support logistics optimization, improve delivery performance, and enhance decision-making.


## Business Problem

Late deliveries directly impact customer satisfaction, operational costs, and supply chain efficiency.

This dashboard was developed to answer key business questions such as:

- Which markets experience the highest number of late deliveries?
- Which shipping modes result in longer delivery delays?
- Which product categories are most affected by delivery issues?
- Which specific products contribute most to delivery problems?
- How have delivery delays changed over time?
- How are orders distributed across different shipping methods?


## Dashboard Features

### KPI Monitoring

The dashboard provides high-level performance indicators including:

- Total Orders
- Total Late Orders
- Late Delivery Percentage

These KPIs allow stakeholders to quickly assess overall delivery performance.


### Market Analysis

Analyzes late orders across different global markets to identify regions requiring operational attention.

Insights include:

- Market-wise distribution of late orders
- Comparison of delivery performance across regions
- Identification of high-risk markets


### Shipping Mode Performance

Evaluates the effectiveness of different shipping methods.

Metrics analyzed:

- Average delivery delay by shipping mode
- Order distribution by shipping mode
- Impact of shipping choice on delivery performance


### Product Category Analysis

Identifies categories with the highest late delivery percentages.

Business value:

- Highlights categories requiring supply chain improvements
- Supports inventory and logistics planning
- Helps prioritize operational interventions


### Product-Level Analysis

Examines products with the highest late delivery percentages.

This enables:

- Identification of problematic products
- Investigation of supplier or fulfillment bottlenecks
- Product-specific performance monitoring


### Trend Analysis

Tracks delivery delay patterns over time.

Benefits:

- Detect seasonal delivery fluctuations
- Monitor operational improvements
- Evaluate long-term performance trends


### Interactive Filtering

Users can dynamically filter the dashboard using:

- Market

This allows stakeholders to explore delivery performance from multiple perspectives.

## Dataset

Dataset Used: DataCo Supply Chain Dataset

Source:
https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis

Data Preparation:
- Removed Customer Password
- Removed Customer Email
- Removed Customer Name fields
- Removed Address fields
- Removed Latitude and Longitude
- Removed Product Image and Description
- Performed data validation and cleaning before analysis


## Key Metrics Used

### Late Delivery Percentage

Measures the proportion of orders delivered late.

### Total Late Orders

Counts all delayed orders.

### Average Delivery Delay

Measures average delay duration across orders.

### Total Orders

Tracks overall order volume.
